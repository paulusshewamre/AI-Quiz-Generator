# AI Study Quiz Generator

An AI-powered web application that generates multiple-choice quizzes from study notes.

## Features

- Paste study notes
- Generate quiz questions using Gemini AI
- Answer questions
- Automatic scoring
- Review correct answers

## Tech Stack

### Frontend

- React
- Vite

### Backend

- Node.js
- Express

### AI

- Gemini API

## Setup

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## API Endpoint

```http
POST /api/generate-quiz
```
