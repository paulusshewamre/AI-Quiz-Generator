# Use Cases

## Actor

Student

---

## Use Case 1: Generate Quiz

### Description

Student generates quiz questions from study notes.

### Steps

1. Student enters notes.
2. Student clicks Generate Quiz.
3. System sends notes to backend.
4. Backend requests quiz generation from AI.
5. Quiz is returned and displayed.

### Expected Result

Quiz questions appear on screen.

---

## Use Case 2: Answer Quiz

### Description

Student answers generated questions.

### Steps

1. Student selects answers.
2. Student submits quiz.
3. System calculates score.

### Expected Result

Score is displayed.

---

## Use Case 3: Review Answers

### Description

Student reviews correct answers.

### Steps

1. Student submits quiz.
2. System displays correct answers.

### Expected Result

Student sees mistakes and correct responses.
